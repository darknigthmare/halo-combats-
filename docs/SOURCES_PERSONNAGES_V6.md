Complément pour Yapyap : [inspection supplémentaire du portfolio primaire de Jeremy Cook](../work/wave6/yapyap_reference_followup.json). Le portrait reste recadré et le key art montre une petite figure assise ; la réserve sur les pieds et le bas des jambes extrapolés n’est pas levée.
